# LocalBiz Reviewer - Owner App

LocalBiz Reviewer is a mobile application for business owners to manage their business, view customer reviews, monitor ratings and sentiments, and generate AI-powered business insights.

This repository contains the **Owner Mobile Application** built using React Native and Expo.

## 🚀 Features

- Owner registration and login
- JWT-based authentication
- Business profile management
- View business information
- Generate and manage QR code for customer reviews
- View customer reviews
- View ratings and average rating
- Review sentiment analysis
- Dashboard with review statistics
- Analytics
- AI-powered business insights
- Notifications for negative reviews
- Secure token storage
- Backend API integration

## 🛠️ Tech Stack

- React Native
- Expo
- Expo Router
- TypeScript
- NativeWind
- Axios
- Expo Secure Store
- Node.js
- Express.js
- MongoDB
- Google Gemini AI
